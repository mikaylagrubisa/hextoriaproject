# Project name: Hextoria

**Brief outline:** Hextoria is a gothic 2D side-scrolling sandbox platformer developed in Python using Pygame. Explore a randomly generated world, jump, build and break blocks and customise your environment.

## General Info:

The purpose of this project was to develop an interactive block building game that combines creativity and platforming mechanics. I wanted to create an engaging experience where players can design and build their own houses, landscapes, and environments.

I undertook this project to challenge myself to apply new programming knowledge and experiment with game development.

## Technologies Used:

- Python - 3.14.6
- Pygame - 2.6.1
- Visual Studio Code
- JSON Library
- Random Library
- Math Library

## Features

- Randomised world generation - different terrain types
- Sandbox building system - place and remove blocks to customise the world
- Advanced collision physics - detect player interaction with solid terrain
- Save and load system - save world modifications and player coordinates using JSON
- Gothic visual design - 16x16 pixel art sprites with a gothic-inspired aesthetic

## Setup:

### Requirements and Dependencies:

The project requires the following installed:

- Python Installed
- Pygame Installed
- Other libraries are included in standard Python

### Installation:

1. Install Python - download and install Python 3.14.6 from python.org

2. Install pygame - open your terminal and run the following command:

   ```bash
   pip install pygame
   ```

3. Download the project - download the GitHub main zip and unzip the folder to your desktop

4. Open the project - open the project folder in Visual Studio Code or run it directly with Python using the command: python main.py

5. Run the game - open the main Python file and run the script to start Hextoria

### Dependicies

The project currently uses Pygame as its external dependency. No requirements.txt or Pipfile.lock is required, as Pygame can be installed directly using pip.

## Usage

### Keybinds:

- A/D = move left and right
- Space = jump
- Space while airborne = double jump
- Shift = sprint
- Mouse left-click = remove blocks
- Mouse right-click = place blocks
- Mouse wheel = adjust camera zoom
- N = save current world and player progress
- M = load previously saved world and player progress
